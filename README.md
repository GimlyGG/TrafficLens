# Centarus

Сборки приложения Centarus для Windows и канал обновлений.

Centarus — монитор трафика и менеджер сетевых настроек: показывает, кто и куда
ходит, измеряет канал, ведёт журнал и управляет сетью системными средствами
Windows. Приложение не устанавливает и не скачивает сторонние программы,
работает с тем, что уже лежит на компьютере.

* Страница с описанием и историей версий: https://GimlyGG.github.io/TrafficLens/
* Канал обновлений: https://raw.githubusercontent.com/GimlyGG/TrafficLens/main/Centarus.update.json

Скачать: вкладка **Releases** этого репозитория.

## Что в релизе

* `Centarus-<версия>.exe` — сборка для Windows 10/11 x64;
* `Centarus-<версия>-src.zip` — её исходники: сборку можно пересобрать самому
  и сверить с бинарником;
* `sha256` каждой сборки — в манифесте канала и на странице.

## Чего в репозитории нет

* сторонних исполняемых файлов и стратегий обхода — они не поставляются;
* обфускации и упаковщиков: внутри обычное приложение на PySide6.

## Сетевые запросы

Приложение обращается в интернет за проверкой обновлений, определением
провайдера и замером канала. Полный список запросов с адресами виден в самом
приложении: страница «О программе».
