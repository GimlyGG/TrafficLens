# Как собрать и проверить

Репозиторий — канал распространения готовых сборок. Исходники лежат рядом с
каждой сборкой (`Centarus-<версия>-src.zip`), их можно собрать самому.

## Сборка из исходников

```
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
build.bat
```

На выходе — `Centarus.exe` в корне проекта. Сборка не воспроизводимая побайтово:
PyInstaller кладёт в файл время и метаданные, поэтому sha256 своей сборки
отличается от релизной. Код при этом тот же.

## Проверки

```
python tools\_test_start.py
python tools\_test_channel.py
python tools\_audit.py 1340x900
```

Все наборы — `tools\_test_*.py`, запускаются по одному из корня проекта.
Тесты работают на временной папке данных и не трогают рабочий профиль.

## Сообщения о проблемах

* об ошибке в приложении — через **Security → Report a vulnerability**
  (см. `SECURITY.md`), чтобы отчёт не был публичным до исправления;
* о сборке — там же, с версией и sha256 из манифеста.

Правки в код через pull request: репозиторий — витрина сборок, поэтому
изменения принимаются только с прогоном проверок.
