# Кодекс поведения

## Кратко

Общаемся по делу и уважительно. Не допускается: оскорбления, травля,
дискриминация, публикация чужих личных данных, спам и реклама.

## Область действия

Всё, что связано с этим репозиторием: обсуждения, отчёты об уязвимостях,
комментарии к изменениям.

## Как сообщить о нарушении

Через приватный Security Advisory (**Security → Report a vulnerability**) —
так обращение видит только мейнтейнер. Анонимность обращения сохраняется.

## Последствия

Нарушение — предупреждение или блокировка в репозитории, по характеру
нарушения. Решения принимает мейнтейнер.

## Основа

Документ опирается на Contributor Covenant 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
изложен коротко и по-русски.
